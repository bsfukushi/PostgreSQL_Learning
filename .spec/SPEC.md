## 2. 構成方針

| 論点 | 決定 |
|---|---|
| 構成 | 積み上げ型の章立て＋各章に「💡 Claude Codeで使うなら」。本冊2冊＋別冊（A案） |
| 本編と別冊の基準 | 知らないと事故る／ズレに気づけない → 本編。知っていると上達する → 別冊 |
| 「なぜ」の置き方 | 本文に一言理由（🔍仕組み／🧭設計理由）、深掘りは章末の「📚 なぜ？豆知識」（折りたたみ）。📜歴史・由来は読み物扱い |
| 設計の学び方 | 5つの問い（型）＋事例（ニュース v1→v3 の試行錯誤）。答えではなく問いを覚える |
| ニュース本文 | 記事と1対1の別テーブルに保存し、全文検索は後から足す |
| 題材が増えたとき | 判断フロー（本編）＋5方式の比較（別冊）。性能は断言せず EXPLAIN ANALYZE で手元計測させる |
| 初期化とバックアップ | 初期化SQL（正）＋ pg_dump（スナップショット）の併用 |
| Claude Code を触る時期 | 第1冊の第5章から（最低限の約束を先に教える） |
| psql と pgAdmin4 | 1章に統合。psql が主（`-c`／`-f`／`\d`／`\copy` に絞る）、pgAdmin4 は「見る道具」 |
| ロール | `postgres`（作る作業だけ）／`learner`（書く役。pglearn の持ち主）／`reviewer`（検証役。読むだけ）。3つとも第4章で作る。`reviewer` への読む権限は `01_schema.sql` の最後で毎回与える（2026-10-14 決定） |
| 検証の仕組み | 検証は必ず別のモデルにさせる。書く役＝Opus（`learner`）、検証役＝Sonnet（`sql-checker` サブエージェント、`reviewer`、読むだけ）。作業フォルダのひな形（`src/workspace/` が正 → 各自の `C:\pglearn\`）で固定する。固定の抜け道（`/model`、呼び出し時のモデル指定）は、人が `/tasks` で検証役のモデルを見ることで補う（フックは使わない）。第5章で導入、第6〜9章の 💡 で毎回使い、第15章で通しの実践（2026-10-14 決定） |
| 検証材料 | a 基準の件数／b 結果と差の理由／c 別解との比較（検証役）／d 境目の行／e 前提／f 依頼とのずれ（検証役）。記号は固定。第6章以降は各章で足す |
| CTE（`WITH`） | 読み方は第9章（段ごとに件数を数える検算として）。`WITH` の中の `DELETE` などの危険な形は第5章（許可前に読む）と第8章。第7章には置かない（2026-10-14 決定） |
| 失敗事例 | 独立章にせず索引化。各章の「起きがちな失敗」が正 |
| チェックリスト | 各章末の `:::check` が正。付録Cはビルドで自動集約 |
| 確認問題 | 「SQLを書く」ではなく「この結果のどこを疑うか」形式。1章3問程度 |

## 4. 独自記法（章MD）

正本は `build/build.py` 冒頭のコメント。要点:

| 記法 | 意味 |
|---|---|
| `:::result N` | 直前の SQL の psql 実行結果（N 行）。`verify_sql.py` が行数を照合する |
| `:::result N wrong` | 誤った結果の印（わざと誤りを見せる例） |
| `:::claude 見出し` | 💡 Claude Codeで使うなら の枠 |
| `:::quiz 問題文` | 確認問題（クリックで答えを表示） |
| `:::why 見出し` | 📚 なぜ？豆知識（折りたたみ） |
| `:::check` | チェックリストに追加する1行 |
| `:::` | 枠の終わり（入れ子可） |
| `[[用語]]` | 用語集（`src/glossary.yaml`）へのホバー説明 |
| `> 🔍` ／ `> 🧭` | 仕組み／設計理由の一言 |

## 5. 資料の中で固定する概念

- **ズレの3分類**: 行が減る（INNER JOIN で相手なし、NULL）／行が増える（1対多の JOIN）／値が変わる（COUNT(*)、タイムゾーン、型変換、照合順序）。第6章で導入し、各章の失敗例にタグ付けする
- **検算の4手順**: ①基準の表の件数 → ②処理後の件数 → ③差の理由を言葉で説明 → ④期待値と比較。③で説明できない結果は使わない
- **設計の5つの問い**: ①1行は何を表すか（粒度）②何で同じものと判定するか ③1つに複数あるか ④あとで変わるか・履歴は要るか ⑤欠けるか・何で検索するか

## 7. 第5章に必ず入れること（Windows 固有のつまずき）

- Claude Code が psql を実行すると、パスワード入力待ちで止まる。`pgpass.conf` か環境変数で渡す必要がある。ただし平文で残るので学習用ロールに限定する
- `postgres`（スーパーユーザー）で Claude Code を接続させない。Claude Code は MCP がなくても Bash から psql を叩けるため、MCP 側を読み取り専用にしても防げない
