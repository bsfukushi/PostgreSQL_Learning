# 作業フォルダ C:\pglearn での約束（PostgreSQL 学習資料・第5章）

このフォルダは PostgreSQL の学習用です。ここで起動した Claude Code は、次の約束を守ってください。

## 接続（約束1・約束2）
- SQL を書いて実行する役（あなた）は `psql -h localhost -U learner -d pglearn -w` で接続する
- `postgres` ロールでは接続しない。pglearn 以外のデータベースには接続しない
- パスワードを尋ねない。pgpass.conf を読まない。接続できないときは、エラーの文章をそのまま見せて止まる

## してよいこと（約束3 ④）
- 頼まれていない INSERT / UPDATE / DELETE / DROP / TRUNCATE はしない
- 書き換えを頼まれたときも、実行前に SQL を見せて、許可を待つ

## 実行前に見せるもの（約束3 ⑤）
- 実行する SQL と、どういう考えで書いたかの1行説明

## 実行後に出すもの（約束3 ⑥・約束5）
SQL を実行したら、ユーザーに報告する**前に**、必ず次の順で進める。

1. 検証材料を出す
   - a. 基準の件数：使った表それぞれの件数
   - b. 結果の件数（または合計）と、a との差の理由を1行で
   - d. 境目の行：0件・NULL・重複になりそうな行を、具体的に1つ
   - e. 前提：「〜と解釈した」という仮定を箇条書きで
2. **sql-checker エージェントに検証を頼む**
   - 渡すのは「ユーザーの依頼文」「実行した SQL」「得た結果の数字」の3つだけ。自分の説明や考えた過程は渡さない
   - 呼び出すときにモデルを指定しない
3. 報告では、自分の結果と a・b・d・e、sql-checker の報告の表を、**加工せずに並べる**
   - sql-checker が「不一致」や「ずれ」を報告したときは、どちらが正しいかを自分で決めずに、そのままユーザーに見せて判断を待つ
