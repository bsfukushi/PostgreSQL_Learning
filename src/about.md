| 章 | 見てほしいところ |

| [第2章 pgAdmin4とpsql](#ch03) | psql の起動、日本語の文字化けの直し方、CSV 出力、pgAdmin4 は見るだけ |

| [第4章 Claude Codeに頼む前の約束](#ch05) | 接続ロール、パスワードの置き場所、指示の最小型、別のモデルによる検証 |
| [第5章 表の形を読む](#ch02) | 型・タイムゾーン・制約、エラーは表が守ってくれた印 |
| [第7章 JOINを読む](#ch07) | 実行結果の表、行が増える・消える図、確認問題、折りたたみの豆知識 |
| [第10章 設計の5つの問い](#ch10) | 生データから設計を導く流れ、ER図、Claude Code への頼み方 |

## 画面の使い方

- 左のメニューで章を選びます。スマートフォンでは、左上の「目次」ボタンで開きます。
- メニュー上の「必修だけ表示」をオンにすると、任意の章（別冊・付録）が隠れます。
- 本文中の点線の付いた語（例：[[主キー]]）にマウスを載せるか、タップすると、用語の説明が出ます。
- 確認問題は「答えを見る」で開きます。章の最後の「読み終えた」を押すと、メニューに ✓ が付きます。読了の記録は、このブラウザの中にだけ保存されます。

## 作り方のメモ（資料作成者向け）

- 正は `src/` 配下の章ごとの Markdown です。`python3 build/build.py` で、この HTML を作り直します。
- 図（ER図）はビルドのときに画像（SVG）にしているので、インターネットにつながっていなくても表示できます。
- 付録A（用語集）、付録C（チェックリスト）、付録D（初期化SQL）は、本文と SQL ファイルから自動で作られます。
- 本文中の SQL と実行結果は、実際の PostgreSQL で実行して確かめます。第7章・第10章は PostgreSQL 16 で確認済み、第2〜5章は未確認です（PostgreSQL 18 での確認はこれから行います）。
